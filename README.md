# أذكار المسلم – Android

تطبيق أندرويد مبني باستخدام Kotlin وJetpack Compose، بواجهة عربية وألوان خضراء وذهبية.

## المزايا
- أذكار مكتوبة جاهزة مع إمكانية إضافة ذكر أو تعديله أو حذفه.
- إضافة صورة ذكر من الهاتف وحفظها داخل التطبيق.
- تحديد عدد التكرارات لكل ذكر مكتوب أو مصوّر.
- عداد مستقل لكل ذكر، مع إعادة تلقائية إلى الصفر عند بلوغ العدد المحدد.
- حفظ الأذكار والعدادات محلياً بعد إغلاق التطبيق.
- إعداد لتفعيل/إيقاف إعادة العداد تلقائياً والاهتزاز.

## بناء APK

### باستخدام Android Studio
1. افتح مجلد المشروع `AzkarMuslim-NewProject` في Android Studio.
2. انتظر اكتمال Gradle Sync وتثبيت Android SDK 35 عند الطلب.
3. اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. ستجد الملف في `app/build/outputs/apk/debug/app-debug.apk`.

### باستخدام GitHub Actions
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد على الفرع `main`.
2. افتح تبويب **Actions** وشغّل **Build Azkar Muslim APK** (أو ادفع commit جديداً).
3. بعد نجاح البناء، افتح نتيجة التشغيل ونزّل artifact باسم `AzkarMuslim-APK`؛ بداخله ملف APK.

> ملف APK غير مرفق في هذه الحزمة؛ يجب تشغيل عملية البناء أولاً باستخدام Android SDK.
